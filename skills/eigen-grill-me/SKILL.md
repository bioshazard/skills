# Eigen Grill Me

Turn an ambiguous problem into a durable decision frame. Ask the fewest questions that resolve the most uncertainty. Do not implement the result until the user confirms shared understanding.

## Wallow

Treat the user's stated question or proposed solution as provisional.

- Inspect the environment and use tools to find discoverable facts. Never quiz the user for facts you can obtain yourself.
- Separate facts from decisions. Research facts; put decisions to the user.
- Inventory the latent questions, constraints, stakeholders, proposed options, and competing values.
- Capture meaningful perspectives without mistaking popularity for correctness.

Keep this inventory private unless showing it helps repair a disagreement.

## Find the eigenquestion

Build a private dependency map: which questions determine which later questions?

Rank candidate questions by:

1. **Downstream collapse** — answering it makes many later answers obvious.
2. **Discrimination** — its answers produce meaningfully different paths.
3. **Durability** — it can become a principle for future decisions.
4. **Independence** — it does not depend on another unsettled question.
5. **User judgment** — it is a genuine choice, not a discoverable fact.

Test each candidate: *If this had a clear answer, which other questions would disappear?*

Rotate the frame when needed. Replace a tactical yes/no or favored solution with the underlying tradeoff, value spectrum, or principle. Name the poles clearly. Prefer one eigenquestion; use two only when independent dimensions jointly define the decision space.

## Grill in rounds

In each round:

1. State the current frame in one sentence when context is needed.
2. Ask exactly one eigenquestion. Ask two only when they are demonstrably orthogonal and best answered together.
3. Give two to four named, mutually distinct options or positions on a spectrum.
4. Recommend an answer and explain the principle behind it.
5. Show the main downstream consequences of each answer so the leverage is visible.
6. Wait for the user's answer.

Do not dump the full question frontier. Do not ask downstream questions whose answers may be settled by the current one.

After every answer:

- Update the frame and collapse questions the answer resolved.
- Surface contradictions or vague terms immediately.
- Recompute the most discriminating unresolved question.
- Continue until no material branch remains silently assumed.

## Make the frame tangible

Use concrete examples to test whether named options mean what both parties think they mean. Name options so they can become shared language.

When two axes materially clarify the space, show a compact 2×2 table and name all four quadrants. Otherwise prefer prose. Distinguish:

- question
- options
- concrete examples
- benefits
- risks
- current choice

## Recover when stuck

Diagnose the shape of the blockage:

- **Ocean** — too few signals or directions. Explore and generate alternatives.
- **Forest** — too much information and circular paths. Change perspective and seek the discriminating dimension.
- **Desert** — attachment to a failing solution. Abandon it temporarily and make a competing option succeed.
- **City** — many valid but tangled routes. Simplify and remove dimensions.

If the frame still does not move, seek another perspective and incorporate it into the option set.

## Propose, then close

When the eigenquestions are exhausted, present:

- problem
- eigenquestion(s)
- named options considered
- chosen principle
- proposed decision
- downstream implications
- remaining risks or genuinely independent open questions

Ask the user to confirm that this captures the shared understanding. Only after confirmation may the session close. Do not implement, publish, message others, or otherwise act on the decision unless the user separately authorizes that action.
